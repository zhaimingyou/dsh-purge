# 1.7.22

本版只动工程链路，不改任何宿主补丁、提示词注入或面板行为。

- **发版自动带摘要**：`publish.yml` 在发布前用 `.github/scripts/release-summary.mjs` 生成「本版摘要」附在发行说明里——补丁总数 / 权限类补丁清单 / 与上一版的补丁增删改 / 注入正文指纹 / 宿主兼容范围 / CI 测试数。装之前先看这段。
- **本地验收命令**：`./tools/dev-loop.sh accept` 跑 `selfcheck` + 探针，把结果记到 `$DSH_HOME/dsh-purge/acceptance/<版本>-<时间>.json`。CI 证明不了“你的宿主加载成功”，这一步只能在本机做。
- **fork 的 CI 收敛**：裁掉 `installer` / `npm-runtime` / `native-prompt-022` 三个三平台集成 job（依赖官方 DSH 安装、electron 与特定 release 资产，fork 上环境不通），保留 `test` + `linux-runtime`；发版门由 `publish.yml` 的全量测试承担。
- 上游体检（`upstream-watch.yml`）与发版（`publish.yml`）两条工作流已在 fork 上跑通：跟 → 自动开 PR，审/停 → 只开 issue。
